# Portfolio content extraction Specification

## Overview
- **Target files:** `scripts/extract-portfolio.mjs` (the generator), and its outputs `src/content/projects.ts`, `src/content/engagement.ts`, `public/images/projects/*`, `public/images/engagement/*`.
- **Source of truth:** Sheng's portfolio repo at `/Users/shengyan/cool-website` (read-only, never modify it):
  - `src/pages/Projects.tsx` — the list (`projects` array: id, n, title, description, tools, github, live, detailPage, image, featured)
  - `src/pages/ProjectDetailPage.tsx` — `projectsData: Record<string, ProjectData>` (title, description, fullDescription, technologies, github, live, reportUrl, image, video, codeSnippet, features, language, diagrams)
  - `src/pages/Engagement.tsx` — `engagements: Engagement[]` (id, n, title, role, period, commitment, summary, image)
  - `src/pages/EngagementDetail.tsx` — `engagementsData` (title, role, period, timeCommitment, work, learned, relevance, image)
  - images in `src/assets/` (imported by those files) and `public/`
- **Approach:** the data objects are plain object literals with image identifiers. The generator slices each literal out of the source text, strips TypeScript type annotations, replaces image identifiers with their asset file names, and evaluates it (e.g. `new Function`). Template literals contain escaped backticks: evaluate as JavaScript so they come out right. Never hand-copy text.

## Images
All outputs go under `public/images/projects/` and `public/images/engagement/`; `src` values are the public paths (`/images/projects/video-to-text.svg`).
- **Project covers:** the list's image for each project. Dark SVG illustrations: copy the SVG as-is, `tone: "invert"` (CSS inverts them to paper tones). For eval-guard use `src/assets/eval-guard.svg` (not the report PNG). Raster images: convert to a 1200×800 greyscale WebP (cover-crop when the image is ≥ 900px wide; otherwise centre it on a #ECE9E2 canvas, scaled to at most 1.5× its native size so it stays crisp), `tone: "photo"`.
- **Diagrams** (video-to-text has three SVGs): copy as-is, `tone: "invert"`. Also add eval-guard's report screenshot (`src/assets/eval-guard-report.png`) as a diagram for eval-guard: greyscale WebP at its native width, `tone: "photo"`, title `"Project report"`, caption `"The consolidated project report: design, calibration, and results on real data."`.
- **Engagement covers:** the list's image for each engagement. Same rules: the YC SVG is a dark illustration (copy, `tone: "invert"`); photos ≥ 900px wide (mailzoo-office.jpg, wharton.avif, nasa-dream-with-us.jpg) cover-crop to 1200×800 greyscale WebP; small logos (cornell.png, download.png, fox.png, math.jpg) go centred on the #ECE9E2 canvas at ≤ 1.5× native size. All `tone: "photo"` except SVGs.
- Use `sharp` from the clone's `node_modules` (it handles AVIF). Name outputs after the entry id (`/images/engagement/mailzoo.webp`). Skip `video` entirely.
- Do not delete or overwrite anything already in `public/images/projects/` except files this script generates (it may overwrite the five existing SVGs with identical copies).

## Text
Keep every string exactly as written in the source (em dashes, quotes and all). Only split paragraphs and trim.

## Verify
- The script prints counts (13 projects, 8 engagements) and fails if any referenced image file is missing.
- `npx tsc --noEmit` passes with the generated files.
- `node scripts/extract-portfolio.mjs` is idempotent (running it twice produces identical files).
